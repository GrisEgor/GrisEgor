# Дом быта — админка и личные кабинеты

`site/` — текущий публичный сайт (v8, восстановлен с Netlify).
`server/` — новый бэкенд (в работе).

## Решения, согласованные с владельцем

- **Арендодатели** — собственники помещений всего здания. Сами ведут объявления в своём
  кабинете, администратор модерирует.
- **Арендатор** в кабинете: избранное и мои заявки; документы и счета; заявки в эксплуатацию.
- **Документы и счета**: собственник загружает PDF (договор, счета, акты) и отмечает «оплачено».
  Сайт счета не формирует, онлайн-оплаты нет.
- **Заявки в эксплуатацию** уходят собственнику помещения и УК. У заявок есть статусы.
  Уведомления получают собственник и УК (о новой заявке) и арендатор (о смене статуса).
  Каналы: PWA web push и боты Telegram/MAX, в идеале все сразу.
- **Хостинг** — российский VPS (152-ФЗ, плюс скорость из Челябинска).
- **Вход**: email + код/пароль, Telegram, Яндекс ID, VK ID.
- **Статистика**: своя в админке (просмотры и заявки по объявлениям, конверсия, графики;
  собственник видит свою) + Яндекс Метрика.
- **Работа по этапам**, после каждого этапа владелец тестирует.

## Стек

Node.js 22 + Fastify 5, PostgreSQL 16, sharp (фото → webp), nodemailer (SMTP).
Кабинеты — vanilla JS без сборки, в стиле сайта. Деплой: Docker Compose + Caddy
(автоматический HTTPS через Let's Encrypt).

## Этап 1

1. Сервер, БД, миграции.
2. Вход (email-код/пароль, Telegram, Яндекс ID, VK ID), сессии в httpOnly-cookie, роли
   admin / landlord / tenant (роль uk — на этапе 2). Аккаунт собственника подтверждает админ.
3. Объявления: статусы draft → pending → published / rejected / archived; правки
   опубликованного объявления идут через модерацию, статус занятости меняется сразу;
   загрузка фото.
4. Заявки на аренду в БД со статусами, уведомления собственнику и админу (Telegram, email).
5. Статистика: показы и открытия карточек, клики, заявки по дням; счётчик Метрики из настроек.
6. UI: админка (дашборд, модерация, объявления, заявки, пользователи, журнал) и кабинет
   собственника (объявления, заявки, статистика, профиль).
7. Публичный сайт берёт объявления из API, форма отправляет в API.
8. Комплект для деплоя + пошаговая инструкция, e2e-тесты.

## Этап 2

Кабинет арендатора (избранное, документы, счета), заявки в эксплуатацию со статусами, роль УК,
уведомления: PWA web push + Telegram/MAX-боты.

## 152-ФЗ (действия владельца)

Уведомление в Роскомнадзор как оператора ПДн; политика обработки ПДн на сайте (шаблон
подготовлю); согласие на обработку в формах; баннер о cookie/Метрике.
